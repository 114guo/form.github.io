# 课表提醒（PWA）

一个可装到手机主屏幕的课程表应用：CSV 导入/导出、手动添加课程、上课前 20 分钟提醒。

## 文件清单

| 文件 | 作用 |
| --- | --- |
| `index.html` | 应用本体（单文件，CSS/JS 全部内联，双击即可用） |
| `课表.csv` | 已从你的课表整理好的课程数据（UTF-8 带 BOM，Excel 可直接打开） |
| `manifest.webmanifest` | PWA 清单（装到主屏、图标、独立窗口） |
| `sw.js` | 服务工作线程（离线缓存） |
| `icon-192.png` / `icon-512.png` | 应用图标 |
| `README.md` | 本说明 |

## 三种用法

### 1. 电脑上直接打开（最省事）
双击 `index.html` 即可。数据保存在浏览器本地，导出 CSV 也能用。
限制：`file://` 属于非安全上下文，**系统通知和离线缓存不可用**（应用内的提醒横幅、倒计时、震动仍可用）。

### 2. 局域网访问（手机也能用，通知可用）
在文件所在目录起一个本地服务：

```bash
# Windows 或 Mac / Linux 均可用（需 Python 3）
python -m http.server 8000
```

手机连同一 WiFi，浏览器打开 `http://你的电脑IP:8000`（`http://localhost:8000` 也属于安全上下文，通知可用）。

### 3. 部署后安装成 App（体验最完整）
把整个文件夹传到 GitHub Pages、Netlify、Vercel 等任意静态托管，HTTPS 打开后：

- Android Chrome：菜单 → “添加到主屏幕”/“安装应用”；
- iPhone Safari：分享 → “添加到主屏幕”（iOS 16.4+ 支持网页通知）。

## 通知机制（重要）

- 应用**打开时**（前台）最可靠：每 30 秒检查一次，进入“课前 20 分钟”窗口就触发应用内横幅 + 系统通知 + 震动。
- 应用**关闭后**能否收到系统通知，取决于浏览器：Android Chrome 安装为 PWA 后通常能收到；iPhone 需要 iOS 16.4+ 且先点过“开启通知”授权。
- 若要“彻底关掉应用也能准点推送”，需要后端定时推送（微信服务号 / FCM / Web Push + 服务器），可在现有代码基础上扩展，这里先不做。

首次使用请点右上角「开启通知」授权。底部「测试提醒」可立即触发一次看效果。

## CSV 格式

表头固定 9 列：

```
课程名称,星期,开始节次,结束节次,开始时间,结束时间,上课地点,周次,备注
```

- `星期`：`星期一`～`星期日`（也接受 1–7）；
- `周次`：逗号分隔列表，如 `2,3,4`；应用内也支持 `2-13`、`2-5,7,9-11` 这类写法；
- 导入会**追加**到现有课程，不覆盖；导出会在当前数据基础上生成新的 `课表.csv`。

## 设置

「设置」里可改两个关键项：

- **学期第一周（周一）日期**：用于算“第几周”，本学期默认 `2026-08-31`（你课表里的第 1 周）。下个学期记得改。
- **提前提醒分钟数**：默认 20。

## 数据存储

课程与设置保存在浏览器 `localStorage`。清除浏览器数据会清空课表，重要数据请用「导出 CSV」备份。
